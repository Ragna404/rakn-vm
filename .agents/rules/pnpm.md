# Package Manager: pnpm

Always use `pnpm` instead of `npm` for JavaScript/Node.js projects:
- `pnpm install` instead of `npm install`
- `pnpm add <pkg>` instead of `npm install <pkg>`
- `pnpm run <script>` instead of `npm run <script>`
- `pnpm dlx` instead of `npx`

If pnpm is not installed, install it with `npm install -g pnpm` first.
